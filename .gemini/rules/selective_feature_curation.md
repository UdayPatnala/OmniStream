# Selective Feature Curation Policy

## Description
Always prioritize features that directly enhance OmniStream's core motives (fast video playback, 2.5D IMAX virtual theater immersion, DSP audio boost, and local media playback) over blind replication of full YouTube platform enterprise clutter.

## Guidelines
1. **Curate for OmniStream's Motive**: Evaluate every new feature request or UI component to ensure it brings tangible value to user streaming, cinema immersion, or performance.
2. **Reject Legacy Clutter**: Do not replicate complex corporate monetization panels, redundant ad manager settings, or unnecessary enterprise overhead from third-party platforms.
3. **Performance & Design Invariants**: Preserve sub-150ms perceived latency, zero Cumulative Layout Shift (CLS = 0), and clean responsive touch controls across mobile and desktop.
