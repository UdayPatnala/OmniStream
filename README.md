# OmniStream

> **Personal Media Experience Platform**: Uniting ad-free web discovery (**U-TUBE**) with a cinematic, fixed-aperture theater experience (**CineMorph**), orchestrated by the **OmniStream Intelligence System (OMS)**.

---

## Key Pillars

1. **U-TUBE**: Lightweight, ad-free YouTube discovery engine with dynamic search, 4-hour cached subscriptions, and client-side keyword recommendations.
2. **CineMorph**: Fixed-aperture theater supporting **1.43:1 (IMAX GT)**, **1.90:1 (Digital IMAX)**, **Original**, and **4:3** formats, featuring CSS3D curved screens, velvet curtains, dynamic ambient lighting, and a real-time Web Audio parametric DSP studio.
3. **OMS (OmniStream Intelligence System)**: 100% free, browser-native intelligence runtime executing on Canvas CV heuristics, Web Audio DSP, and off-thread Web Workers with progressive multi-tier fallback.

## Quick Start

### Prerequisites
- Node.js >= 18.0.0
- npm or bun

### Installation
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Run Full 5-Tier Test Harness (47 suites, 218 tests)
```bash
npm test
```

### Production Build
```bash
npm run build
```
