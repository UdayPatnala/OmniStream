1. EXECUTIVE PRODUCT STRATEGY & PHILOSOPHY RULES
========================================================================================================================
OmniStream is an autonomous, high-performance video viewing platform designed to combine low-cost self-hostability with
ultra-immersive cinema presentation.

Core Philosophical & Operational Directives:
------------------------------------------------------------------------------------------------------------------------
Rule 1.1: SELECTIVE FEATURE CURATION OVER BLIND CLONING
  - OmniStream explicitly rejects blind feature replication. Only features that directly enhance cinematic immersion 
    and long-form video playback are implemented and preserved.
  - Short-form vertical feeds ("Shorts") consume excessive API quota, fragment user attention, and bloat network telemetry. 
    Shorts navigation and routes were systematically purged from the codebase.

Rule 1.2: INVISIBLE ALGORITHMIC BEHAVIOR
  - "The user should experience the result. The user should never notice the algorithm."
  - Auto-reframing, scene-cut flushes, dead-zone hysteresis, and low-pass light smoothing operate invisibly behind the UI.

Rule 1.3: THE VIDEO IS PRIMARY CONTENT
  - The virtual cinema environment (2.5D seating, velvet curtains, halogen spotlights, Ambilight radial bloom) is strictly 
    secondary. The video plane remains the primary visual focal element at all times.

Rule 1.4: ZERO DECEPTIVE CLAIMS
  - Software DSP and spatial audio filters do not fake physical cinema hardware. Features are explicitly named after 
    their actual technical mechanisms: "Spatial Web Audio 3D", "Dialogue Boost Peaking Filter", "Fixed Aperture 1.43:1".

2. DUAL-ENGINE ARCHITECTURE & GATEWAY ROUTING SYSTEM
========================================================================================================================
OmniStream operates on two independent presentation engines governed by a central Experience Gateway.

Engine A: U-Tube V1 (Classic High-Density Video Feed)
  - Purpose: Rapid content discovery, channel browsing, and standard video streaming.
  - Layout: Top header with category pill bar (All, Music, Gaming, Tech, Web Development, Lo-Fi, Live), 
    responsive multi-column video grid (`grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4`).
  - Watch Interface: Split view featuring primary video player, channel metadata card, collapsible description, 
    interactive AI copilot tab, and right-hand recommendation column.

Engine B: CineMorph V2 (Neural Virtual Cinema Hall)
  - Purpose: Ultra-immersive cinematic movie theater playback.
  - Environment: 2.5D visual theater room with opening red velvet curtains, 4K Intro Bumper Video, 
    scalloped ceiling halogen spotlights, cyan neon wall columns, 3D surround speaker cabinets, low floor step lights, 
    and live real-time reactive Ambilight radial bloom canvas.
  - Screen Engine: Fixed Aperture Model ("Box With A Hole") supporting `1.43:1` (IMAX GT Vertical Aperture), 
    `1.90:1` (IMAX Digital Widescreen Aperture), `21:9` (UltraWide Cinema), and `original` (Native Directorial Framing).

Gateway Router Scoping (`RootRouter` in `src/App.tsx`):
  - Preference State: `rootLandingPreference` stored in Zustand (`'ask' | 'v1' | 'v2'`).
  - When `rootLandingPreference === 'v1'`: `/` renders U-Tube V1 Home feed.
  - When `rootLandingPreference === 'v2'`: `/` renders CineMorph V2 Cinema Portal.
  - When `rootLandingPreference === 'ask'`: `/` renders Dual-Experience Gateway (`src/pages/RootLanding.tsx`).
  - Dedicated Gateway URL: `/landing` or `/gateway` allows the user to re-evaluate or reset their preference anytime.
  - Top Navigation Toggle: `v2 AI` badge navigates to `/cinemorph`; `v1` badge navigates to `/home`.

4. CINEMORPH V2 ADAPTIVE LARGE-FORMAT INTELLIGENT SCREEN ENGINE (192-SECTION SPECIFICATIONS)
========================================================================================================================

4.1 CORE ARCHITECTURAL MODEL: FIXED APERTURE MODEL ("BOX WITH A HOLE")
------------------------------------------------------------------------------------------------------------------------
In CineMorph V2, the visible screen aperture stays fixed in aspect ratio, while the underlying video plane transforms 
(`scale`, `translateX`, `translateY`) behind the aperture mask.

4.2 PRESENTATION MODES
------------------------------------------------------------------------------------------------------------------------
1. `MODE_A: ORIGINAL` (Reference Baseline)
   - Native uncropped source framing (`16:9`, `2.39:1`, `4:3`).
   - `scale(1.0) translateY(0%)`. Zero ML crop.

2. `MODE_B: LARGE_FORMAT_1_43` (Vertical Immersive IMAX GT)
   - Visible Aperture Aspect Ratio: `143 / 100` (`1.43:1`).
   - Native 1.43:1 IMAX trailers (e.g. S.S. Rajamouli's Varanasi 1.43:1 Trailer) render at `scale(1.0) translateY(0%)` 
     without horizontal pillarboxing.
   - Reframe Mode `face-priority`: `scale(1.15) translateY(-3%)`.

3. `MODE_C: LARGE_FORMAT_1_90` (Wide Immersive Digital IMAX)
   - Visible Aperture Aspect Ratio: `190 / 100` (`1.90:1`).
   - Center Reframe Mode: `scale(1.0) translateY(0%)`.
   - Reframe Mode `face-priority`: `scale(1.10) translateY(-2%)`.

4. `MODE_D: 21:9` (UltraWide Cinema)
   - Visible Aperture Aspect Ratio: `21 / 9`.
   - Center Reframe Mode: `scale(1.33) translateY(0%)`.
   - Reframe Mode `face-priority`: `scale(1.35) translateY(-4%)`.

4.3 CANDIDATE WINDOW SCORER & COST EQUATION
------------------------------------------------------------------------------------------------------------------------
Total Candidate Cost = ContentLoss + FaceLoss + TextLoss + SubtitleLoss + CompositionLoss + TransitionCost

- Subtitle Safe Guard: When captions/subtitles are enabled (`subtitlesOn === true`), 
  the engine flushes `targetScale = 1.0` and `targetTranslateY = 0%` instantly to prevent subtitle text clipping.
- Confidence Fallback: When analysis confidence < 0.60, framing automatically reverts to `scale(1.0) translateY(0%)`.
- Dead-Zone Hysteresis: Micro-shifts (< 3.5% translateY delta or < 0.03 scale delta) are ignored to eliminate camera chasing.
- Low-Pass Temporal Alpha Filter: `lastScale = lastScale + 0.15 * (nextScale - lastScale)`.

5.1 WEB AUDIO NODE GRAPH PIPELINE

------------------------------------------------------------------------------------------------------------------------
+-------------------+------------+------------------+--------------+-------------+--------------------+
| Preset Name       | Bass Gain  | Dialogue Gain    | Treble Gain  | Surround 3D | DRC Compressor     |
+-------------------+------------+------------------+--------------+-------------+--------------------+
| dialogue-boost    | -4 dB      | +18 dB (2.5kHz)  | +8 dB        | Enabled     | Thresh: -24dB, R:12|
| bass-heavy        | +20 dB     | +2 dB            | +4 dB        | Enabled     | Disabled           |

6.1 DIRECT YOUTUBE LINK PARSER
------------------------------------------------------------------------------------------------------------------------
Implemented in `src/lib/utils.ts` (`extractYouTubeId`):
- Accepts full YouTube URLs (`https://www.youtube.com/watch?v=5qap5aO4i9A`), short URLs (`https://youtu.be/5qap5aO4i9A`), 
  embed URLs (`https://www.youtube.com/embed/5qap5aO4i9A`), and 11-character video IDs (`5qap5aO4i9A`).
- `PlaybackService` and `CineMorphLanding` check `extractYouTubeId(input)` first. If valid, the engine directly 
  fetches video metadata and launches `/theater/${id}` immediately without search API latency.

6.2 MULTI-STRATEGY QUERY INTELLIGENCE (`queryIntelligence.ts`)
------------------------------------------------------------------------------------------------------------------------
- Language Detector: Identifies script types (English ASCII, Telugu `\u0C00-\u0C7F`, Hindi `\u0900-\u097F`, Tamil `\u0B80-\u0BFF`).
- Strategy Generator: Produces query variants (base normalized, language-tagged, recency-filtered).

6.3 SINGLE-FLIGHT CACHE MANAGER (`cacheManager.ts`)
------------------------------------------------------------------------------------------------------------------------
- Prevents redundant in-flight network requests for identical search queries.
- Caches query candidate video IDs for 10 minutes (`CACHE_TTL_MS = 600,000`).

6.4 DYNAMIC KEYWORD RECOMMENDATION ENGINE (`recommendations.ts`)
------------------------------------------------------------------------------------------------------------------------

9. EXHAUSTIVE BUG HISTORY, ROOT-CAUSE DIAGNOSTICS & RESOLUTION REGISTRY
========================================================================================================================

Bug #1: Watch History `openCount` Over-counting
  - Symptom: A single view of a video recorded 100+ "open" events in history analytics.
  - Root Cause: `addToHistory` in `store.ts` was doing `openCount: prevOpens + 1` every 5 seconds on progress ticks.
  - Resolution: Changed logic to `openCount: prevOpens > 0 ? prevOpens : 1`, preserving `openCount` on progress updates.

Bug #2: Inactive / Static Ambilight Radial Bloom
  - Symptom: Theater walls remained dark purple without reacting to video scene color shifts.
  - Root Cause: `dynamicBloomColor` state in `CineMorphTheater.tsx` remained null, falling back to static gradient.
  - Resolution: Linked `adaptiveCinemaEngine.ambientLight.lowpassColor` directly to the radial bloom canvas style (`blur(75px)`).

Bug #3: Seating Tier Top Shadows & Gray Box Overlaps
  - Symptom: Blocky gray rounded rectangles and dark upward shadow blurs overlapped the lower video frame.
  - Root Cause: Top back-tier seat row and `shadow-[0_-8px_20px_rgba(0,0,0,0.9)]` cast shadows upward onto the video.
  - Resolution: Removed top back-tier row and stripped upward box-shadows, positioning a clean front row below the screen.

Bug #4: Skipped Theater Intro Video Bumper & Curtains
  - Symptom: Entering theater mode bypassed the red velvet curtain reveal and 4K intro video reel.
  - Root Cause: `curtainAnimationEnabled` defaulted to `false` in `store.ts`.
  - Resolution: Set `curtainAnimationEnabled: true` by default in `store.ts`.

Bug #5: Screen Shrinking into a Tiny Square Center Box (`4:3` Ratio)
  - Symptom: Video frame collapsed into a small 4:3 box in the center of the screen.
  - Root Cause: `frameAspectRatio` was cycled or restored as `'4:3'`, enforcing CSS `aspect-ratio: 4/3`.
  - Resolution: Restricted `cycleAspectRatio` to cinema formats (`['original', '1.43:1', '1.90:1', '21:9']`) and auto-reset obsolete ratios to `16:9` / `original`.

Bug #6: Master Volume Attenuation on `original` Audio Curve
  - Symptom: Master audio volume was significantly lower inside CineMorph than on native YouTube.
  - Root Cause: Dynamics Compressor node set threshold to `-50dB` when DRC was disabled.
  - Resolution: Set compressor threshold to `0dB` and ratio to `1:1` for `original` preset.

Bug #7: Replaying Movie Preserved End Watch Position
  - Symptom: Clicking "Replay Movie" restarted playback, but refreshing the page restored the end position (100% finished).
  - Root Cause: Replay click handler set `played = 0`, but did not update `watchPositions[id]` in localStorage.
  - Resolution: Added explicit `saveWatchPosition(id, 0, duration)` and `addToHistory(video, 0, duration)` calls to the Replay handler.
