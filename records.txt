1. PRODUCT STRATEGY, PHILOSOPHY & BOUNDARIES
================================================================================
OmniStream is an independent, high-performance, cinematic video experience platform.

Core Motive Rules:
- SELECTIVE FEATURE CURATION OVER BLIND CLONING: Only retain features that elevate
  the user's viewing experience. Features like "Shorts" that consume excessive 
  metadata and encourage fragmented attention were explicitly purged.
- INVISIBLE ALGORITHMIC BEHAVIOR: The user should experience the result; the user 
  should never notice the algorithm.
- THE VIDEO IS PRIMARY CONTENT: The virtual cinema environment, seating, curtains, 
  and ambient bloom remain secondary to the video itself.
- NO FAKE CLAIMS: No fake "Dolby" or fake "IMAX" claims that software reproduces 
  physical cinema hardware. Features are explicitly named for their DSP or aperture 
  mode (e.g. Spatial 3D Audio, Dialogue Boost, Large-Format 1.43:1 Aperture).

4. CINEMORPH V2 ADAPTIVE LARGE-FORMAT INTELLIGENT SCREEN ENGINE
================================================================================
Architectural Core: Fixed Aperture Model ("Box With A Hole")

Concept:
- The virtual cinema screen maintains a FIXED visible aperture.
- The source video plane sits BEHIND the aperture mask.
- Video transforms (`scale`, `translateY`) move the video plane behind the mask 
  ONLY to center subjects (faces, leadroom, text/subtitles).

Presentation Modes:
1. `MODE_A: ORIGINAL` (Reference Baseline)
   - Unmodified source framing & aspect (`16:9`, `2.39:1`, `4:3`).
   - `scale(1.0) translateY(0%)`. Zero ML crop.
2. `MODE_B: LARGE_FORMAT_1_43` (Vertical Immersive IMAX GT)
   - Aperture Aspect Ratio: `1.43:1` (`aspect-[143/100]`).
   - Native 1.43:1 trailers render at 100% full height (`scale(1.0)`).
3. `MODE_C: LARGE_FORMAT_1_90` (Wide Immersive Widescreen)
   - Aperture Aspect Ratio: `1.90:1` (`aspect-[190/100]`).
   - Fits modern widescreen digital IMAX framing without letterbox padding.

Candidate Window Scorer & Sticky Hysteresis:
- Calculates Total Cost = ContentLoss + FaceLoss + TextLoss + SubtitleLoss + CompositionLoss + TransitionCost.
- Subtitle Safe Guard: When captions/subtitles are active (`subtitlesOn === true`), 
  smart cropping is instantly bypassed (`scale = 1.0, translateY = 0%`) to prevent caption clipping.
- Confidence Fallback: Reverts to original composition when confidence drops below 0.60.
- Sticky Hysteresis: Micro-shifts (< 3.5% delta) are ignored; candidate updates require 
  a +15% score improvement before shifting.

5. WEB AUDIO DSP NEURAL AUDIO ENGINE
================================================================================
Built on native Web Audio API in `src/lib/cinemorph/audioEngine.ts`:

Audio Pipeline Nodes:
Source Node -> Bass Biquad Filter (Lowshelf) -> Dialogue Biquad Filter (Peaking 2.5kHz) -> Treble Biquad Filter (Highshelf 7kHz) -> Dynamics Compressor -> Stereo Panner -> Analyser -> Destination

Presets:
- `dialogue-boost`: Bass -4dB, Dialogue +18dB, Treble +8dB, DRC ON.
- `bass-heavy`: Bass +20dB, Dialogue +2dB, Treble +4dB, DRC OFF.
- `spatial-3d`: Bass +8dB, Dialogue +10dB, Treble +14dB, DRC ON, Surround ON.
- `night-compression`: Bass -6dB, Dialogue +12dB, Treble -2dB, DRC ON.
- `original`: Bass 0dB, Dialogue 0dB, Treble 0dB, DRC OFF, Compressor Threshold 0dB (0% attenuation pass-through for 100% native master volume).

6. DISCOVERY, PLAYBACK PIPELINE & CACHE MANAGER
================================================================================
Managed via `PlaybackService` (`src/lib/services/playbackService.ts`):

1. Direct YouTube URL & ID Parser:
   - When a YouTube link (`https://www.youtube.com/watch?v=...`, `https://youtu.be/...`) 
     or 11-char ID is pasted, `extractYouTubeId` extracts the video ID directly and 
     navigates to `/theater/${id}` immediately without search latency.

2. Multi-Strategy Search Loop:
   - Generates normalized strategies (e.g. English, Telugu, Hindi, Tamil).
   - Single-Flight Request Deduplication via `CacheManager` prevents duplicate network calls.

3. Dynamic Keyword Recommendation Engine:
   - `getRecommendedVideos(popular, history, subscriptions, collections, searchHistory)`:
     Extracts high-frequency keywords from recent & most viewed history items.
   - Searches YouTube Data API for extracted keywords, ensuring fresh, non-repeating recommendations.

7. MISTAKES, MOST OCCURRING ERRORS & ROOT-CAUSE RESOLUTIONS
================================================================================
Here is the detailed log of bugs encountered and fixed during development:

1. ISSUE: History `openCount` Over-counting on Ticks
   - Root Cause: `addToHistory` in `store.ts` was doing `openCount: prevOpens + 1` 
     every 5 seconds during periodic playback progress updates.
   - Fix: Changed `openCount` logic to `openCount: prevOpens > 0 ? prevOpens : 1`, 
     preserving `openCount` on progress updates and updating history in-place (`history[video.id]`).

2. ISSUE: Ambient Bloom / Ambilight Glow Static or Inactive
   - Root Cause: `dynamicBloomColor` state in `CineMorphTheater.tsx` remained null, 
     falling back to a static purple background gradient.
   - Fix: Linked `adaptiveCinemaEngine.ambientLight.lowpassColor` directly to the 
     radial bloom background style (`blur(75px)`), producing real-time reactive Ambilight shifts.

3. ISSUE: Seating Tier Shadows & Gray Box Overlaps on Video
   - Root Cause: Top back-tier row of 10 gray seat boxes and `shadow-[0_-8px_20px_rgba(0,0,0,0.9)]` 
     cast upward shadows over the video.
   - Fix: Removed top back-tier row and stripped upward box-shadows, placing a clean 
     front seating row below the video aperture.

4. ISSUE: Theater Intro Video Bumper Skipped on Entry
   - Root Cause: `curtainAnimationEnabled` defaulted to `false` in `store.ts`.
   - Fix: Changed `curtainAnimationEnabled: true` by default in `store.ts`, enabling 
     curtains opening reveal and 4K intro bumper video (`/Create_a_professional_cinemati.mp4`).

5. ISSUE: Screen Shrinking into a Tiny Center Box (`4:3` Ratio)
   - Root Cause: `frameAspectRatio` was cycled or restored as `'4:3'`, collapsing CSS `aspect-ratio: 4/3`.
   - Fix: Restricted `cycleAspectRatio` to cinema formats (`['original', '1.43:1', '1.90:1', '21:9']`) 
     and auto-reset obsolete ratios to `16:9` / `original`.

6. ISSUE: Original Audio Preset Volume Very Low
   - Root Cause: Dynamics Compressor node set threshold to `-50dB` when DRC was OFF, 
     squishing uncompressed audio.
   - Fix: Set compressor threshold to `0dB` and ratio to `1:1` for `original` preset.

7. ISSUE: Replaying Movie Retained End Watch Position
   - Root Cause: Clicking "Replay Movie" set `played = 0`, but did not update `watchPositions[id]`.
   - Fix: Added `saveWatchPosition(id, 0, duration)` and `addToHistory(video, 0, duration)` 
     inside the Replay Movie click handler.
