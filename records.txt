SECTION 1: EXECUTIVE PRODUCT STRATEGY, PHILOSOPHY & MOTIVE BOUNDARIES
====================================================================================================================================================

1.1 CORE PRODUCT MOTIVES
OmniStream is engineered to transform online video viewing from a fragmented, ad-cluttered browser experience into a high-performance, 
cinematic viewing environment. The system balances ultra-lightweight client execution with deep visual and acoustic customization.

1.2 MANDATORY ENGINEERING DIRECTIVES

Rule 1.2.1: SELECTIVE FEATURE CURATION OVER BLIND CLONING
  - Software components must earn their place in the codebase by directly serving long-form cinematic video playback.
  - Non-aligned, high-overhead features like short-form video feeds ("Shorts") were systematically purged.
  - Purging Shorts reduced unnecessary API quota consumption, saved 6.00 kB JS bundle size, and eliminated metadata polling overhead.

Rule 1.2.2: INVISIBLE ALGORITHMIC BEHAVIOR
  - "The user should experience the result. The user should never notice the algorithm."
  - Re-framing transitions, temporal low-pass smoothing, dead-zone hysteresis, and Ambilight color shifts must execute seamlessly.
  - No jarring screen crops, frame jumps, artificial camera shaking, or sudden brightness flickering.

Rule 1.2.3: THE VIDEO PLANE IS PRIMARY CONTENT
  - The virtual cinema auditorium (2.5D seating, velvet curtains, halogen spotlights, Ambilight radial bloom) is strictly secondary.
  - The video frame always remains the primary visual focal element of the application.

Rule 1.2.4: ZERO DECEPTIVE CLAIMS
  - Software DSP and spatial audio filters do not fake physical cinema hardware.
  - Features are explicitly named after their actual technical mechanisms (e.g. "Spatial Web Audio 3D", "Dialogue Boost Peaking Filter", 
    "Fixed Aperture 1.43:1 Vertical Aperture").

SECTION 4: CINEMORPH V2 ADAPTIVE LARGE-FORMAT INTELLIGENT SCREEN ENGINE (192-SECTION SPECIFICATIONS)
====================================================================================================================================================

4.1 FIXED APERTURE MODEL ("BOX WITH A HOLE")
The screen container presents a fixed visible aperture mask. The video element sits behind the mask.
CSS transforms (`scale`, `translateX`, `translateY`) move the video plane behind the aperture window to frame subjects accurately without cropping out vital content.

4.2 MATHEMATICAL PROOF OF APERTURE SCALING & RATIOS
To fill an aperture window without inner letterbox or pillarbox bars inside the player, the scale factor is mathematically derived from the ratio between the source aspect ratio ($A_{src} = 16/9 = 1.7777$) and the aperture ratio ($A_{aperture}$):

1. `MODE_A: ORIGINAL`: Aspect Ratio `16 / 9` ($1.7777$). Scale = $1.0$. Zero cropping, zero scaling.
2. `MODE_B: LARGE_FORMAT_1_43`: Aperture Aspect Ratio `143 / 100` ($1.4300$).
   $$\text{Scale Factor} = \frac{16/9}{1.43} = \frac{1.7777}{1.4300} = \mathbf{1.25}$$
   - Center Mode: `scale(1.25) translateY(0%)`. Fills 100% of the 1.43:1 vertical aperture height cleanly without inner black bars.
   - Face-Priority Mode: `scale(1.28) translateY(-3%)`.
3. `MODE_C: LARGE_FORMAT_1_90`: Aperture Aspect Ratio `190 / 100` ($1.9000$).
   $$\text{Scale Factor} = \frac{1.9000}{16/9} = \frac{1.9000}{1.7777} = \mathbf{1.08}$$
   - Center Mode: `scale(1.08) translateY(0%)`. Fills 100% of the 1.90:1 widescreen aperture width cleanly.
   - Face-Priority Mode: `scale(1.12) translateY(-2%)`.
4. `MODE_D: 21:9`: Aperture Aspect Ratio `21 / 9` ($2.3333$).
   $$\text{Scale Factor} = \frac{21/9}{16/9} = \frac{2.3333}{1.7777} = \mathbf{1.33}$$
   - Center Mode: `scale(1.33) translateY(0%)`. Fills 100% of the 21:9 UltraWide aperture width.
   - Face-Priority Mode: `scale(1.35) translateY(-4%)`.

4.3 CANDIDATE WINDOW SCORER & COST EQUATION
Total Candidate Cost = ContentLoss + FaceLoss + TextLoss + SubtitleLoss + CompositionLoss + TransitionCost
- Subtitle Safe Guard: When captions are enabled (`subtitlesActive === true`), smart cropping is instantly bypassed (`scale = 1.0, translateY = 0%`) to guarantee caption text visibility.
- Confidence Fallback: Reverts to original uncropped framing when analysis confidence < 0.60.
- Dead-Zone Hysteresis: Shifts smaller than 3.5% translateY delta or 0.03 scale delta are ignored to prevent camera jitter.
- Low-Pass Temporal Smoothing: `lastScale = lastScale + 0.15 * (nextScale - lastScale)`.

SECTION 9: EXHAUSTIVE BUG LOG, DIAGNOSTIC HISTORY & ROOT-CAUSE RESOLUTIONS
====================================================================================================================================================

Bug #1: History `openCount` Over-counting
  - Root Cause: `addToHistory` in `store.ts` did `openCount: prevOpens + 1` every 5 seconds on progress ticks.
  - Resolution: Changed to `openCount: prevOpens > 0 ? prevOpens : 1`, updating history in place without over-counting opens.

Bug #2: Inactive / Static Ambilight Bloom
  - Root Cause: `dynamicBloomColor` state in `CineMorphTheater.tsx` remained null, falling back to static purple gradient.
  - Resolution: Linked `adaptiveCinemaEngine.ambientLight.lowpassColor` directly to the radial bloom container (`blur(75px)`).

Bug #3: Seat Top Drop-Shadow Blurs Overlapping Video Frame
  - Root Cause: Top back-tier seat row and `shadow-[0_-8px_20px_rgba(0,0,0,0.9)]` cast upward shadows onto the video.
  - Resolution: Removed top back-tier row and stripped upward drop-shadows, placing a clean front row below the screen aperture.

Bug #4: Skipped Theater Intro Video Bumper & Curtains
  - Root Cause: `curtainAnimationEnabled` defaulted to `false` in `store.ts`.
  - Resolution: Set `curtainAnimationEnabled: true` by default in `store.ts`.

Bug #5: Screen Shrinking into a Tiny Center Square (`4:3` Ratio)
  - Root Cause: `frameAspectRatio` was cycled or restored as `'4:3'`, collapsing CSS `aspect-ratio: 4/3`.
  - Resolution: Restricted `cycleAspectRatio` to cinema formats (`['original', '1.43:1', '1.90:1', '21:9']`) and auto-reset obsolete ratios to `16:9` / `original`.

Bug #6: Master Volume Attenuation on `original` Audio Preset
  - Root Cause: Dynamics Compressor node set threshold to `-50dB` when DRC was disabled.
  - Resolution: Set compressor threshold to `0dB` and ratio to `1:1` for `original` preset.

Bug #7: Replaying Movie Preserved End Watch Position
  - Root Cause: Replay click handler set `played = 0`, but did not update `watchPositions[id]` in localStorage.
  - Resolution: Added explicit `saveWatchPosition(id, 0, duration)` and `addToHistory(video, 0, duration)` calls to the Replay handler.

Bug #8: Tiny Video Box Inside 1.43:1 and 1.90:1 Aperture Containers
  - Root Cause: 16:9 YouTube video elements inside 1.43:1 aperture containers left inner black letterbox bars inside the player when unscaled (`scale(1.0)`).
  - Resolution: Updated scale formulas in `frameEngine.ts` and `adaptiveCinemaEngine.ts` to `scale(1.25)` for 1.43:1 and `scale(1.08)` for 1.90:1, filling the aperture window completely.
